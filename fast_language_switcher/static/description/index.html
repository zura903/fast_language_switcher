Fast Language Switcher
v1.1.0 LGPL-3 Odoo 17 · 18 · 19
Odoo Module · Tools

Switch language.
Instantly.

A flag-based language picker that lives in the Odoo top bar. One click or one keyboard shortcut — no page navigation, no friction.

Installation Configuration →
COMPAT Odoo 17.0 Odoo 18.0 Odoo 19.0

Features

🏳️
Flag in Systray

Active language flag and short code always visible next to the user avatar.

🖱️
Click Dropdown

Click the flag to open a clean list of all installed languages.

⌨️
Keyboard Overlay

Press your shortcut to open a macOS-style floating picker and cycle languages.

⚙️
Configurable Shortcut

Set any modifier + key combo from General Settings — captured live, no typing.

🔄
Cycle with Keyboard

Each press advances the highlight; release the modifier to apply instantly.

🌐
Flag Derivation

Flags are auto-derived from ISO territory codes (e.g. fr_FR → 🇫🇷).

Installation

01
Copy the module

Place the fast_language_switcher folder into your Odoo addons path, or a custom addons path defined in odoo.conf.

02
Restart the server

Restart the Odoo server process so it discovers the new module directory.

03
Install from Apps

Go to Settings → Apps, search Fast Language Switcher, and click Install.

04
Add a second language

At least two languages must be installed (Settings → Translations → Languages) for switching to be useful.

Configuration

Changing the keyboard shortcut
Default shortcut is CtrlL
1.Open Settings → General Settings
2.Scroll to the Fast Language Switcher section
3.Click Change next to Keyboard Shortcut
4.Press your desired combo — e.g. CtrlShiftL or AltL — it's captured automatically
5.Click Save
RuleDetail
Modifier requiredMust include Ctrl, Alt, Meta (⌘), or Shift
Non-modifier keyOne letter, digit, or function key
Storage formatLowercase +-separated string, e.g. ctrl+l
System parameter keyfast_language_switcher.shortcut

Usage

🖱️
Click (Dropdown)

Click the flag icon in the systray → a dropdown lists all active languages → click any to switch immediately.

⌨️
Keyboard (Overlay)

Press CtrlL to open the floating overlay. Press again to cycle. Release modifier to apply. Esc or backdrop click to cancel.

FAQ

The shortcut conflicts with my browser.

Change it in General Settings to a combo your browser doesn't reserve, e.g. CtrlShiftL or AltL.

The overlay shows the wrong shortcut hint.

After saving a new shortcut, hard-reload with CtrlShiftR / CmdShiftR to clear the asset cache.

Only one language appears in the list.

Install additional languages via Settings → Translations → Activate a Language (Odoo 16+) or Settings → Translations → Languages.

The flag shows 🌐 instead of a proper flag.

Flags are derived from the ISO territory code (e.g. fr_FR → 🇫🇷). Languages with only a two-letter code and no territory, like en, fall back to the globe emoji.
